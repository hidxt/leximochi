## 关于第 2 项的重要说明

- **数据不进入 Git 仓库**：即使已获授权，29 MB 的第三方数据文件也不适合长期存放在 Git 历史中；且项目许可证为 Apache-2.0，把第三方数据一并纳入会带来许可边界模糊。因此采用「**下载 + 导入**」流程：
  - 下载：`npm run fetch:dataset -w @leximochi/server`（代理优先、失败直连，保存到 `data/imports/`，该目录已被 `.gitignore` 忽略）
  - 导入：`npm run import:wordbook -w @leximochi/server -- --file data/imports/cet4.jsonl --key cet4 --name "四级核心词" --system`
- 若你希望改为**随仓库分发数据**（例如让新克隆者开箱即有词库），请告知，我会：把数据放到 `data/` 之外的独立目录、在该目录附加独立的许可证说明文件（写明作者授权条款），并在 `README` 中说明其许可与项目 Apache-2.0 的边界。**在你说可以之前我不会这样做。**
- **待补充信息（请提供其一）**：作者授权的具体条款（例如 MIT / CC-BY-4.0 / 仅限非商业学习用途 / 允许再分发），以及凭证（issue 链接、邮件或截图）。我会据此更新本表，并在授权范围不覆盖「再分发」时保持当前的不入库策略。

## 数据字段映射与已知限制（导入时）

见 `docs/dataset-evaluation.md` 第 2 节。要点：

- 使用 `full` 档（含音标/例句/同义/同根词）；`simple` 档字段不足。
- 同一单词在源文件中会出现多行（不同词性/义项），导入时按归一化词形**合并并保留全部义项**。
- 来源无音频文件：`ukspeech`/`usspeech` 是第三方发音服务的查询标识，**不作为本项目的音频 key 导入**，因此音频字段为空（播放相关功能需另寻授权音频源或后续 TTS）。
- 来源的 `descCn` 是「中释」这类标签而非英文释义，**不映射为 `definitionEn`**。
- 未映射字段：`realExamSentence`/`exam`（真题句子）、`remMethod`（来源提供的记忆法，非 AI 内容，写入 AI 表会造成来源误标）。
